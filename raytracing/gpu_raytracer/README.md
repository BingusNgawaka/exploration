# GPU Raytracer
[Ray Tracing In One Weekend](https://raytracing.github.io/books/RayTracingInOneWeekend.html)

## Requirements
c++ and cmake.

## Compiling and Running
in this dir make a build folder then cd into it, cmake .., make, then run the main exec produced.
```bash
mkdir build
cd build
cmake ..
make
./main
```
